# 内容配方：教材、卡片、题目怎么写

内容层是这类产品**唯一真正耗工时**的部分。配方给的是结构和判定标准，不是模板套话。

## 一、微型教材：六段式

每个区域一篇。目标是让人**在 2 分钟内搞懂一个反直觉的点**，而不是讲完整个章节。

```
钩子 → 一句话本质 → 生活类比 → 具体例子 → 常见误解 → 一图流 + 关键数字 → 出门小检查
```

| 段 | 要求 | 反例（不合格） |
|---|---|---|
| **钩子** | 从学习者的真实挫败感切入，"你一定有过这种体验" | "本节将介绍间隔重复的概念" |
| **一句话本质** | 全篇最该被记住的那句，独立成句，不含术语 | 一段三行的学术定义 |
| **生活类比** | 用的日常场景；**必须** | 省略，或用另一个学术概念解释 |
| **具体例子** | 有情境、有数字或动作；**必须** | 抽象复述一遍本质 |
| **常见误解** | 说清坑在哪，最好带实验/研究背书 | "要注意不要误用" |
| **一图流** | ASCII 图，箭头和空格排版 | 一句"如图所示" |
| **关键数字** | 阈值、参数、效应量 | 无数字 |
| **出门小检查** | 4 选 1，判的是理解不是记忆 | 复述型问题（"本文提到了哪几点"） |

### 示例（合格）

> **钩子**：你是不是总在「忘光了之后」才想起复习，于是只能从头再学一遍？
> **一句话本质**：要在「刚好快忘」的那一刻复习，而不是忘了之后再补救。
> **类比**：给花浇水：天天浇会涝死，一个月不浇会旱死。最好是在土「快干了但还没干透」的时候浇——每一次都刚好救活它，而且它一次比一次耐旱。
> **例子**：周一背 20 个单词。如果周二早上就自测（快忘但没全忘），答对后下次可以隔 3 天；如果拖到下周一才看（早就忘光），等于从头学，白费上周的功夫。
> **误解**：最常见的误区是「趁热打铁当天多刷几遍」。当天反复练只会让你在当天很顺，对一周后毫无帮助。
> **一图流**：`忘记 100% ──▶ 复习点 ● ──▶ 又忘记 ──▶ 复习点 ●`
> **数字**：最佳间隔约为目标保持期的 10%–20%。每日新卡 15–25 张。
> **出门检查**：一周后要默写，今天刚背完，什么时候自测最好？（A 明天 / B 今天连刷五遍 / C 考前突击 / D 忘光再重学）

### 判定标准

写完逐条自查：**钩子有没有戳到挫败感？类比是不是日常场景？例子有没有具体情境？数字有没有给？** 四条缺任一，重写。

## 二、卡片：四段式（禁止干巴巴的定义）

```
【一句话】…… 【类比】…… 【例子】…… 【数字】……
```

- **【一句话】**和**【类比】**必带
- **【例子】**和**【数字】**至少有一个
- 另可加【坑】【出处】【用法】【判据】等

### 反例（不合格，禁止这样写）

```
Q: Dunlosky 评审中拿到「高效用」的两项技术是？
A: 练习测试（d≈0.50）与分散练习（d≈0.60）。其余多为中或低效用。
```

问题：这是**检索用**的答案，不是**理解用**的解释。初见面时摊开给用户，他还是不懂为什么。

### 正例（合格）

```
【一句话】所有方法里，只有这两项拿到了最高级「高效用」。
【类比】如果学习是把钉子钉进墙，重读是用手按住钉子，练习测试是拿锤子敲——按一百次不如敲三下。
【例子】同样 30 分钟复习一章：A 重读两遍，B 合书默写一遍再对答案。一周后 B 明显记得更牢。
【数字】练习测试 d≈0.50，分散练习 d≈0.60。
```

### 写卡片的其它规矩

- **一张卡只问一个点**。问「XX 是什么，有什么特点，怎么用」的卡没法评分，也没法做最小单元调度。
- **正面问句要能闭卷答**。避免「下列哪个说法正确」这种再认型问题（除非刻意训练判别）。
- **保留一句简短答案**用于简答关的关键词比对，完整解释放 `vivid`。
- **`vivid` 是初见面机制能成立的前提**——没有它，初见面就只是把干定义又念了一遍。

## 三、简答题（闭卷关）

- 题干明确要求「闭卷写出」，并点明要几个要素
- `keys` 给 3–5 个关键词，命中 **≥60%** 判通过
- `tip` 是提示，触发即扣分（提示会消除提取难度）
- `a` 给完整参考要点，阅卷时展示

## 四、交错判别题（BOSS 关）

结构：**情境 → 先判别类别 → 再选做法**。判别错记「条件误判」，做法错记「规则误用」。

- 情境要**真实、有代入感**（"三类数学题分开都会做，一混在一起就选错公式"）
- 4 个选项里，错的那个要**错得像真会犯的**（继续刷题海、抄十遍、换本教材），不要放明显荒谬的
- `why` 要解释**为什么其他三个不对**，不只是为什么这个对

## 五、费曼讲解题

- `topic` 一个概念，`audience` 一个具体的人（"一个从没听过这个词的初中生"）
- `jargon` 列术语：检测到就判定「没讲人话」，要求换大白话或类比
- `prompts` 是讲不通时学伴抛出的追问，要**真像外行会问的**（"这句话什么意思""能换个例子吗""如果反过来还成立吗"）
- 判定：长度 ≥60 字 + 无术语 + 有例子

## 六、错因归因题

- `ans` 给一个**具体的**错误作答，越像真人写的越好
- 四类选项固定：事实缺失 / 规则误用 / 条件误判 / 表达不清
- `why` 要说明**补法**，不只是归类理由

## 七、创作关的硬指标

用 `checks` 数组，每项给 `keys`（任一命中即算达成）。典型六项：

编码动作、间隔排期、闭卷提取、复盘归因、迁移变式、AI 红线。

达成 ≥4 项判通过。

## 八、教材与卡片的绑定（最关键的一步）

每篇教材用 `teaches` 列出它覆盖的卡片 id：

```js
{ id: "ls2", r: "store", ..., teaches: ["c05","c06","c07","c08","c09"] }
```

**约束**：

1. 每篇教材的 `teaches` 只能覆盖**同区域**的卡（`c.r === lesson.r`）
2. 全部教材的 `teaches` 并集必须**等于全部卡片**（不能有孤儿卡）
3. 教材关必须排在它所在区域的训练关之前

这三条不满足，「没学过的卡不许考」就是空话。**交付前用脚本验一遍**（脚手架的测试里有对应断言）。
