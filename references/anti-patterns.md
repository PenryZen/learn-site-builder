# 反模式：三个真实踩过的坑

这三个坑是照着"学习科学"写方案、做出来的东西却违反学习科学的实例。**同一个病根犯了三次**：把"先编码，后提取"当成一句写在文档里的口号，没有落到代码和数据结构上。

## 坑 1：一上来就闪卡

**现象**：打开首页 → 六个区域 → 点进去就是闪卡自评。方案里白纸黑字写着"先编码后提取"，做出来却让人默写还没学过的东西。

**为什么错**：闪卡是**提取工具**，不是教材。没编码就提取 = 让人凭空回忆一个没见过的概念，挫败感极强，而且学不到东西。

**修法**：每个区域改成「教材关 → 训练关」成对，**教材没读完，训练关不解锁**。教材用微型教材六段式（见 content-recipes.md）。

**验收**：全新进度下点最靠后的训练关，应该进不去。

---

## 坑 2：卡片答案是干巴巴的定义

**现象**：卡片背面写着"练习测试 d≈0.50、分散练习 d≈0.60"。用户反馈："缺乏生动形象的解释，不好理解"。

**为什么错**：那是**检索用**的简短答案，不是**理解用**的解释。初见面时摊开给用户看，他还是不懂为什么。

**修法**：卡片答案改四段式 `【一句话】【类比】【例子】【数字】`。类比必带，例子/数字至少一个。

**验收**：随机抽一张卡，确认它讲清了"为什么"，而不只是"是什么"。

---

## 坑 3：闪卡里的内容前面根本没学过

**现象**：修了坑 1 之后，用户发现"闪卡初训给的卡片，我在前面都还没学过"——因为教材只讲了原理，没有逐条覆盖卡片内容。

**为什么错**：教材和卡片是两套平行内容，没有绑定关系。读完教材只懂了原理，具体的卡面知识仍然是陌生的。

**修法**：
1. 教材用 `teaches` 字段**显式绑定**它覆盖的卡片 id，通关后自动批量标记为已学
2. 加**初见面机制**兜底：撞到未学卡先摊开完整解释，读完才转自测，且此时不给评分按钮

**验收**：通关一篇教材后进「今日复习」，队列里只出现该区域的卡；若有卡没被 `teaches` 覆盖（`learned=false`）却进了队列，它必须显示「未学·初见面」并先给解释。

---

## 病根总结

三次都栽在**同一件事**：学习科学的原则如果只是出现在 README 里，就不会被执行。必须变成：

- **数据结构约束**（`teaches` 绑定，没有绑定就编译不过/测试不过）
- **状态约束**（`learned` 标志，没有它就不给提取入口）
- **流程约束**（解锁顺序由 `DATA.levels` 数组定义，教材关必须在前）

**比在文档里写十遍"先编码后提取"都管用。**

## 交付前自检清单

逐条过，任一不过就返工：

- [ ] 全新进度下，最靠后的训练关**进不去**（被教材关挡住）
- [ ] 全新进度下，去「今日复习」**没有卡**（队列只从读完的教材出卡），卡面说「还没有可复习的卡」
- [ ] 通关一篇教材后，队列里**只有该区域**的卡；其他区域的卡即使旧记录 `seen>0` 也不出现
- [ ] `learned=false` 的卡进了队列时，显示**「未学·初见面」并先给解释**，**无评分按钮**
- [ ] 教材通关后，该区域所有卡 `isLearned=true`；未达 80% 不标记
- [ ] 任意一张卡片的答案**不是**干巴巴的定义，含【一句话】+【类比】
- [ ] 每篇教材的 `teaches` 只覆盖**同区域**的卡
- [ ] 全部卡都被某篇教材覆盖，**无孤儿卡**
- [ ] 看材料/翻页**不给 XP**，只有提取行为给分
- [ ] 已学卡的背面**默认收起**（要凭回忆）
- [ ] 提供**导出**（Anki CSV + 日志 JSON）
- [ ] 界面上**没有**"学习金字塔 90%""保证提分""一万小时必成专家"这类说法
- [ ] 效应量与参数标注为**量级参照**，不是提分承诺
- [ ] AI 学伴**默认不给答案**（只追问），切批改模式才评价

## 另外两个常见跑偏

**跑偏 A：把 PDF 做成网页 + 加徽章。**
判定：页面上的主要动作是「阅读」和「点下一页」，XP 授予「完成阅读」。这是用替代指标冒充学会。修法见硬规则 3。

**跑偏 B：追求内容量，一口气做 30 关 300 张卡。**
判定：教材和卡片质量必然崩（类比凑不出、例子编不出）。宁可 **4–6 个区域、30–60 张卡**做扎实，每篇教材都真有类比和例子，也不要铺满。
