# 学习科学速查：方法分级、效应量与参数

用于选方法、定参数、给用户解释「为什么这么设计」。效应量是**量级参照**，不是提分承诺。

## 一、证据分级（选方法的唯一依据）

按 Dunlosky 等（2013, *Psychological Science in the Public Interest*）对十类学习技术的系统评审：

| 级别 | 方法 | 效应量 | 怎么用 |
|---|---|---|---|
| **高效用** | 练习测试（主动回忆） | d≈0.50 | 无条件优先，作为主干 |
| **高效用** | 分散练习（间隔重复） | d≈0.60 | 无条件优先，作为主干 |
| 中效用 | 交错练习 | d≈0.55 | 单类熟练后叠加 |
| 中效用 | 精细提问 | d≈0.55 | 理解因果时用 |
| 中效用 | 自我解释 | d≈0.45 | 解题/推理时用 |
| 中效用 | 具体例子化 | d≈0.55 | 抽象规则配样例 |
| 低—中 | 双重编码 | 理解情境稳健 | 图文同构才有效 |
| 辅助 | 康奈尔尔笔记、SQ3R | 中等 | 只做配角 |
| 辅助 | 思维导图 | 证据混合 | 关系词比线条重要 |
| 低效用 | 重读、划重点、单纯总结 | — | 不做主策略 |
| 技能领域 | 刻意练习 | 解释力有限 | 技能训练用 |
| 辅助 | 成长型思维 / 元认知 | d≈0.08–0.20 | 提升持续投入 |
| 教学框架 | 布鲁姆分层 | — | 当任务菜单 |
| **误传** | 学习金字塔 5%–90% | 查无实证 | 当反面教材 |

**产品含义**：主干只有两件事——**提取练习**和**间隔重复**。其余方法是叠加项，不是替代品。

## 二、关键实验与结论

- **Roediger & Karpicke（2006）**：延迟测验（2 天、1 周）中，先前测试组保持显著更好；5 分钟时重学反而占优。→ 别用「刚看完就测」判断效果；也别把"读得顺"当掌握。
- **Karpicke & Blunt（2011）**：检索练习优于概念图。→ 思维导图不能替代提取。
- **Macnamara & Maitra（2019）**：刻意练习只能解释专家表现差异的一部分。→ 「一万小时」是量级结论，不是通用门槛。
- **Ericsson（1993）**：音乐学院研究，一流小提琴家 20 岁前累计约一万小时。→ 引用时必须带上领域限定。
- **学习金字塔**：5%/10%/20%/30%/50%/75%/90% 这套数字不见于 Edgar Dale 原著。→ 可以说"增加生成与输出的方向有依据"，但**不能把数字当选型依据**。

## 三、可直接使用的参数

| 参数 | 取值 | 场景 |
|---|---|---|
| 最佳复习间隔 | 目标保持期的 **10%–20%** | 一周后考试→隔天；一月后考试→3–6 天 |
| 每日新卡上限 | **15–25 张** | 标准是「明天不欠债」，不是越多越好 |
| 交错启用门槛 | 单类正确率 **约 80%** | 低于此就混合会把没学会误判成学不会 |
| 难度自适应目标正确率 | **约 80%** | 每 5 题错 1 题，维持心流 |
| 关卡通关线 | **80%** | 与上面同一条曲线 |
| SM-2 EF | 初始 **2.5**，截断 **1.3–2.5** | 答对 `I(新)=I(旧)×EF`；答错归零回炉 |
| 简答命中率阈值 | **60%** 关键词 | 关键词命中比例判通过 |
| 番茄时长 | 25+5，每 4 个长休 | 只作时间盒，别把番茄数当学习指标 |
| 布鲁姆六级 | 记忆→理解→应用→分析→评价→创造 | 任务菜单，非线性阶梯 |
| Duolingo 2024Q4 | 日活 4050 万（+51%）、月活 1.167 亿、付费 950 万 | 参与指标，**不等于学懂** |

## 四、四阶段闭环（页面区域的划分依据）

```
输入编码 → 巩固存储 → 提取应用 → 复盘迭代
   ↑                                  │
   └──────────────────────────────────┘
```

- **编码**：浏览/预提问（SQ3R）、具体例子化、双重编码
- **存储**：间隔重复（SM-2）、康奈尔尔线索栏
- **提取**：主动回忆、交错练习、费曼讲解、自我解释
- **复盘**：错因四类归因、元认知校准、布鲁姆高阶任务

**顺序是设计变量**。同样的方法，先编码后提取 vs 先提取后编码，效果完全不同。区域顺序、关卡解锁顺序都必须服从这条链。

## 五、四类错因（复盘墙的分类依据）

| 错因 | 表现 | 补法 |
|---|---|---|
| 事实缺失 | 知识点本身记错/不知道 | 最小单元闪卡 |
| 规则误用 | 知道规则但应用方式错 | 分步练 |
| 条件误判 | 没判断适用条件 | 交错判别训练 |
| 表达不清 | 思路对但输出含糊 | 口述/重写 |

**注意**：表达类错误下降可能只是熟练度提升，知识性错误占比下降才算真进步。

## 六、元认知校准

`校准误差 = |预测正确数 − 实际正确数| ÷ 总题数`

产品做法：**每道题先让用户选 1–5 的把握度，再作答**，累计误差展示在复盘墙。误差越小说明越清楚自己哪里不会。

## 七、游戏化：什么有效、什么有害

**最小有效单元 = 反馈 + 进步 + 下一次稍难的挑战。** 不是徽章。

有效：连胜（小承诺）、进度可视化、难度自适应、失败可重试、即时具体反馈。
有害：把 XP 授予「完成任务」而非「通过提取」、排行榜挤压内在动机、用参与指标冒充学习指标。

**给什么行为发分，用户就会练什么行为。** 如果按「在健身房待多久」发奖牌，大家就会在更衣室刷手机。
